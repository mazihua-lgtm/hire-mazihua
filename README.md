# hire-mazihua

Personal services portfolio — AI agent deployment, RAG systems, financial data tools.

🌐 **Live site:** https://mazihua-lgtm.github.io/hire-mazihua/

## What's here

Single-page portfolio. Self-contained HTML/CSS, no framework, no build step.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Edit

Open `index.html`. The structure is:
- Hero
- Stats
- Services (6 cards)
- Portfolio (8 projects)
- Process (4 steps)
- CTA + footer

## Deploy

Push to `main` branch — GitHub Pages auto-deploys.
